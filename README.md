# WizIOT - AI-Powered B2B Fleet Management & Telematics Platform

WizIOT is an enterprise-grade B2B SaaS platform providing real-time GPS tracking, EV Battery Management System (BMS) telemetry, fuel theft prevention, ADAS video telematics, and WHO GDP-compliant cold chain logistics.

## Key Features & Stack

- **Framework**: Next.js 16 (App Router, Turbopack, SSG/Static Route Generation)
- **Styling**: Vanilla CSS (Tailored Design System, Modern Dark Modes, Glassmorphism)
- **SEO & E-E-A-T**: Comprehensive JSON-LD Schemas (`Organization`, `TechArticle`, `FAQPage`, `BreadcrumbList`), dynamic XML Sitemap (`sitemap.xml`), and OpenGraph metadata
- **Asset Engine**: 560+ B2B telematics technical guides with unique WebP visual assets, topic-matched internal cross-links, and interactive solution detail modals

## Getting Started

First, install dependencies and run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Production Build

To build the application for production:

```bash
npm run build
npm run start
```
